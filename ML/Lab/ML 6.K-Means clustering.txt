Implement K-Means clustering/ hierarchical clustering on sales_data_sample.csv dataset.  
Determine the number of clusters using the elbow method. 
Dataset link : https://www.kaggle.com/datasets/kyanyoga/sample-sales-data



import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns

from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans
from scipy.cluster.hierarchy import linkage, dendrogram, fcluster




df = pd.read_csv("sales_data_sample.csv", encoding="unicode_escape")

df.head()





print("Dataset Shape:")
print(df.shape)

print("\nDataset Information:")
df.info()

print("\nStatistical Summary:")
display(df.describe())

print("\nColumn Names:")
print(df.columns)








print(df.isnull().sum())







# Data Preprocessing
# Select Numerical Features
features = df[
    [
        "QUANTITYORDERED",
        "PRICEEACH",
        "SALES",
        "ORDERNUMBER"
    ]
].dropna()

features.head()









# Standardize the Data
scaler = StandardScaler()

X_scaled = scaler.fit_transform(features)

print("Data shape after scaling:", X_scaled.shape)








# Part A — K-Means Clustering
# Elbow Method
inertia = []

K = range(1, 11)

for k in K:
    model = KMeans(
        n_clusters=k,
        random_state=42,
        n_init=10
    )
    
    model.fit(X_scaled)
    inertia.append(model.inertia_)







# Plot the Elbow Curve
plt.figure(figsize=(8, 5))

plt.plot(K, inertia, marker='o')

plt.title("Elbow Method - Optimal K")
plt.xlabel("Number of Clusters (K)")
plt.ylabel("Inertia (Within-Cluster Sum of Squares)")

plt.grid(True)

plt.show()








# Part B — Apply K-Means
# Train the K-Means Model
kmeans = KMeans(
    n_clusters=4,
    random_state=42,
    n_init=10
)

df["Cluster"] = kmeans.fit_predict(X_scaled)







# Display Cluster Centers
print("Cluster Centers:\n")

print(kmeans.cluster_centers_)






# Check Number of Points in Each Cluster
print(df["Cluster"].value_counts().sort_index())




# K-Means Visualization
plt.figure(figsize=(10, 6))

sns.scatterplot(
    x="PRICEEACH",
    y="SALES",
    hue="Cluster",
    data=df,
    palette="viridis"
)

plt.title("K-Means Clustering Visualization")

plt.xlabel("Price Each")
plt.ylabel("Sales")

plt.legend(title="Cluster")

plt.show()








# Cluster Summary
cluster_summary = df.groupby("Cluster")[
    ["SALES", "PRICEEACH", "QUANTITYORDERED"]
].mean()

print("Cluster Summary:\n")

display(cluster_summary)

2. Theory
1. Clustering

Clustering is an unsupervised machine learning technique used to group similar data points into clusters.

In this practical, sales records are grouped based on their quantity ordered, price, sales amount, and order number.

2. Unsupervised Learning

Unsupervised learning is a machine learning technique in which the model learns patterns from data without predefined output labels.

4. Feature Scaling

Feature scaling brings all numerical features into a similar range.

In this practical, StandardScaler is used to standardize the data.

It converts features to approximately:
- Mean = 0
- Standard deviation = 1
Scaling is important because K-Means uses distance calculations.

5. K-Means Clustering

K-Means is an unsupervised machine learning algorithm used to divide data into K different clusters based on similarity.

Working:
1. Select the number of clusters (K).
2. Initialize K cluster centroids.
3. Calculate the distance of each point from the centroids.
4. Assign each point to its nearest centroid.
5. Recalculate the centroids.
6. Repeat until the clusters become stable.
6. Elbow Method

The Elbow Method is used to determine the optimal number of clusters.
- Runs K-Means with different K values.
- Calculates inertia for each K.
- Plots a graph of K against inertia.
- Selects the point where the decrease in inertia starts becoming slower (elbow point).
7. Inertia

Inertia measures the sum of squared distances between data points and their assigned cluster centroids.

Lower inertia indicates more compact clusters.

9. Cluster Summary

Calculated the average sales, price, and quantity ordered for each cluster to understand the characteristics of different groups.

7. Important Formulas for Viva
Euclidean Distance
\[
d(x,y)=\sqrt{\sum_{i=1}^{n}(x_i-y_i)^2}
\]

Centroid Calculation
\[
C=\frac{1}{n}\sum_{i=1}^{n}x_i
\]

Inertia
\[
Inertia=\sum_{i=1}^{K}\sum_{x\in C_i}
||x-\mu_i||^2
\]

Where:
- K = Number of clusters.
- \(C_i\) = Data points in cluster i.
- \(\mu_i\) = Centroid of cluster i.
