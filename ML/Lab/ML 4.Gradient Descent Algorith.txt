Implement Gradient Descent Algorithm to find the local minima of a function. 
For example, find the local minima of the function y=(x+3)² starting from the point x=2.


import matplotlib.pyplot as plt

# Function
def f(x):
    return (x + 3) ** 2

# Derivative
def df(x):
    return 2 * (x + 3)

# Initial values
x = 2
learning_rate = 0.1
precision = 0.00001
max_iterations = 100

# Store values for plotting
x_values = [x]
y_values = [f(x)]

# Gradient Descent
for i in range(max_iterations):

    gradient = df(x)

    # Gradient Descent formula
    x_new = x - learning_rate * gradient

    x_values.append(x_new)
    y_values.append(f(x_new))

    if abs(x_new - x) < precision:
        break

    x = x_new

# Display result
print("Starting point:", 2)
print("Number of iterations:", i + 1)
print(f"Local minimum occurs at x = {x_new:.5f}")
print(f"Minimum value of y = {f(x_new):.5f}")

# Plot the function
x_plot = [i / 10 for i in range(-100, 41)]
y_plot = [f(i) for i in x_plot]

plt.plot(x_plot, y_plot, label="y = (x + 3)^2")
plt.scatter(x_values, y_values, label="Gradient Descent Steps")

plt.xlabel("x")
plt.ylabel("y")
plt.title("Gradient Descent")
plt.legend()
plt.grid()
plt.show()

1. Aim
To implement the Gradient Descent Algorithm in Python to find the local minimum of the function (y=(x+3)^2), starting from the initial point x=2.

2. Theory
1. Gradient Descent

Gradient Descent is an optimization algorithm used in Machine Learning to find the minimum value of a function.

It works by repeatedly updating the input value in the direction opposite to the gradient (slope) until it reaches the minimum point.

2. Objective of Gradient Descent

The main objective is to minimize the function by finding the value of x where the function has the lowest value.

3. Given Function
y=(x+3)^2

- Initial point: x=2
- Learning rate: 0.1
- Precision: 0.00001
- Maximum iterations: 100
4. Derivative

The derivative represents the slope of a function.

For the given function:
{dy}/{dx}=2(x+3)

5. Gradient Descent Formula
x_{new}=x_{old}-alpha f'(x)

Where:
- x_{new} = Updated value of x.
- x_{old} = Previous value of x.
- alpha = Learning rate.
- f'(x) = Derivative of the function.
6. Learning Rate

Learning rate controls how big a step the algorithm takes towards the minimum point.
- Small learning rate: Slow convergence.
- Large learning rate: May overshoot the minimum.
- Proper learning rate: Helps reach the minimum efficiently.
7. Precision

Precision is the stopping condition of the algorithm.

In this practical, the algorithm stops when the difference between two consecutive x values becomes smaller than 0.00001.

8. Working of the Algorithm
1. Initialize x = 2.
2. Calculate the derivative.
3. Update x using the Gradient Descent formula.
4. Repeat the process until the stopping condition is satisfied.
5. Display the minimum value and plot the graph.
3. Expected Output
The minimum point of the function is:
Local minimum point
x = -3.00000

Minimum value of y = 0.00000

The algorithm starts at x = 2 and gradually moves towards x = -3.
4. Conclusion
Successfully implemented the Gradient Descent Algorithm to find the local minimum of the function \(y=(x+3)^2\), starting from x = 2. The algorithm repeatedly updates the value of x using the derivative and learning rate until the minimum point is reached.
