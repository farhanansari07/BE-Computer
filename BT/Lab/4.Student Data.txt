Q. Write a program in solidity to create Student data. Use the following constructs: 
• Structures 
• Arrays 
• Fallback 
Deploy this as smart contract on Ethereum and Observe the transaction fee and Gas values.

-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
Code
-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

//SPDX-License-Identifier: UNLICENSED
pragma solidity ^0.8.0;

contract StudentData{
    struct Student{
        string name;
        uint rollno;
    }

    Student[] public studentArr;

    function addStudent(string memory name,uint rollno) public{
        for(uint i=0;i<studentArr.length;i++){
            if(studentArr[i].rollno==rollno){
                revert("Student with roll no already exists!");
            }
        }
        studentArr.push(Student(name,rollno));
    }

    function displayAllStudents() public view returns(Student[] memory){
        return studentArr;
    }

    function getStudentByIndex(uint index) public view returns(Student memory){
        require(index<studentArr.length || index > studentArr.length,"Index out of bound");
        return studentArr[index];
    }

    function getLengthOfStudents() public view returns(uint){
        return studentArr.length;
    }


}

 1. Aim
To write and deploy a smart contract using Solidity to store and manage student information using Structures, Arrays and Fallback functions on the Ethereum blockchain, and observe the transaction fee and gas values.

 2. Theory
Solidity is a high-level programming language used to develop smart contracts on the Ethereum blockchain.

In this practical, a smart contract named StudentData is created to store and manage student information using the following constructs:
1. Structure (struct):
A structure is a user-defined data type that groups multiple variables of different data types under one name. Here, the Student structure contains the student's name and roll number.
2. Array:
An array is a collection of elements of the same data type. Here, a dynamic array named studentArr stores multiple student records.
3. Fallback Function:
A fallback function is a special unnamed function that executes when a contract receives a call with unmatched function data or, depending on its declaration, receives Ether without matching a receive function. It is declared using the fallback keyword.
4. Gas and Transaction Fee:
Gas represents the computational effort required to execute operations on Ethereum. Transaction fees are calculated based on gas used and the effective gas price.
The contract provides functions to add student details, display all students, retrieve a student by index and find the total number of students.

 8. Gas and Transaction Fee (Very Important)
The examiner may specifically ask you about this because it is mentioned in the practical statement.

What is Gas?
Gas is the unit that measures the computational work required to execute operations on the Ethereum blockchain.

What is Transaction Fee?
Transaction fee is the amount of Ether paid to execute a transaction on Ethereum.

Formula:
Transaction Fee=Gas Used * Effective Gas Price

For example, suppose:
- Gas used = 50,000
- Gas price = 20 Gwei
Then:
50,000 * 20=1,000,000 Gwei =  0.001 ETH

Fallback vs Receive
Fallback	Receive
Handles unmatched function calls.	Handles empty calldata with Ether.
Declared using fallback().	Declared using receive().
Can be payable.	Must be payable.
Executes when no receive function handles an empty call.	Executes when Ether is sent with empty calldata.

Memory vs Storage
Memory	Storage
Temporary data location.	Permanent contract data location.
Exists during function execution.	Persists on the blockchain.
Generally cheaper than storage.	Generally more expensive to modify.
