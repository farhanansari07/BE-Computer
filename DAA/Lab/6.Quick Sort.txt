import java.util.*;

public class QuickSort {

    static Random rand = new Random();

    // Deterministic Quick Sort
    static int partition(int a[], int low, int high) {

        int pivot = a[high];
        int i = low - 1;

        for (int j = low; j < high; j++) {

            if (a[j] < pivot) {
                i++;

                int temp = a[i];
                a[i] = a[j];
                a[j] = temp;
            }
        }

        int temp = a[i + 1];
        a[i + 1] = a[high];
        a[high] = temp;

        return i + 1;
    }

    static void quickSort(int a[], int low, int high) {

        if (low < high) {

            int pi = partition(a, low, high);

            quickSort(a, low, pi - 1);
            quickSort(a, pi + 1, high);
        }
    }

    // Randomized Partition
    static int randomPartition(int a[], int low, int high) {

        int randomIndex = rand.nextInt(high - low + 1) + low;

        int temp = a[randomIndex];
        a[randomIndex] = a[high];
        a[high] = temp;

        return partition(a, low, high);
    }

    // Randomized Quick Sort
    static void randomizedQuickSort(int a[], int low, int high) {

        if (low < high) {

            int pi = randomPartition(a, low, high);

            randomizedQuickSort(a, low, pi - 1);
            randomizedQuickSort(a, pi + 1, high);
        }
    }

    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        System.out.print("Enter number of elements: ");
        int n = sc.nextInt();

        int a[] = new int[n];

        System.out.println("Enter array elements:");

        for (int i = 0; i < n; i++) {
            a[i] = sc.nextInt();
        }

        int b[] = a.clone();

        // Deterministic Quick Sort
        quickSort(a, 0, n - 1);

        System.out.println("Deterministic Quick Sort:");
        System.out.println(Arrays.toString(a));

        // Randomized Quick Sort
        randomizedQuickSort(b, 0, n - 1);

        System.out.println("Randomized Quick Sort:");
        System.out.println(Arrays.toString(b));

        sc.close();
    }
}

#include <bits/stdc++.h>
using namespace std;
// Deterministic Partition Function
int deterministicPartition(vector<int> &arr, int low, int high) {
    int pivot = arr[low];
    int i = low;
    int j = high;

    while (i < j) {
        while (arr[i] <= pivot && i <= high - 1) {
            i++;
        }
        while (arr[j] > pivot && j >= low + 1) {
            j--;
        }
        if (i < j) swap(arr[i], arr[j]);
    }
    swap(arr[low], arr[j]);
    return j;
}

// Randomized Partition Function
int randomizedPartition(vector<int> &arr, int low, int high) {
    int randomIndex = low + rand() % (high - low + 1); // Random index between low and high
    swap(arr[low], arr[randomIndex]); // Swap the randomly chosen pivot with the first element
    return deterministicPartition(arr, low, high); // Use deterministic partition with the random pivot
}

// Quick Sort function with user-selected partition
void quickSortHelper(vector<int> &arr, int low, int high, bool isRandomized) {
    if (low < high) {
        int pIndex;
        if (isRandomized) {
            pIndex = randomizedPartition(arr, low, high);
        } else {
            pIndex = deterministicPartition(arr, low, high);
        }
        quickSortHelper(arr, low, pIndex - 1, isRandomized);
        quickSortHelper(arr, pIndex + 1, high, isRandomized);
    }
}

// Main Quick Sort function
vector<int> quickSort(vector<int> arr, bool isRandomized) {
    quickSortHelper(arr, 0, arr.size() - 1, isRandomized);
    return arr;
}

 1. Aim
To implement and analyze Deterministic and Randomized Quick Sort algorithms in Java and compare their time and space complexities.

 2. Theory
Quick Sort is a sorting algorithm based on the Divide and Conquer technique. It is used to arrange elements in ascending or descending order.

It works by selecting an element called a Pivot and dividing the array into two parts:
- Elements smaller than the pivot.
- Elements greater than the pivot.
The same process is repeated recursively until the entire array is sorted.
Divide and Conquer Technique

Quick Sort follows three steps:
1. Divide: Select a pivot and partition the array into two parts.
2. Conquer: Recursively sort the left and right subarrays.
3. Combine: The array becomes sorted after the recursive calls finish.

Types of Quick Sort
1. Deterministic Quick Sort
- Selects the pivot using a fixed method.
- In our program, we select the last element as the pivot.
- Its performance depends on the input arrangement.

2. Randomized Quick Sort
- Selects the pivot randomly from the array.
- Swaps the randomly selected pivot with the last element.
- Reduces the chances of repeatedly getting an unbalanced partition on particular input arrangements.

Difference Between Deterministic and Randomized Quick Sort

 4. Algorithm

A. Deterministic Quick Sort
1. Start.
2. Select the last element as the pivot.
3. Partition the array around the pivot.
4. Place smaller elements on the left and larger elements on the right.
5. Recursively sort the left subarray.
6. Recursively sort the right subarray.
7. Stop when the subarray has zero or one element.

B. Randomized Quick Sort
1. Start.
2. Select a random element as the pivot.
3. Swap the selected pivot with the last element.
4. Partition the array around the pivot.
5. Recursively sort the left subarray.
6. Recursively sort the right subarray.
7. Stop when the subarray has zero or one element.

5. Step-by-Step Explanation
Suppose the input array is:
[45, 12, 89, 23, 5, 34]

A. Deterministic Quick Sort
1. Select the last element 34 as the pivot.
2. Move elements smaller than 34 to the left.
3. Place the pivot in its correct position.
4. Recursively sort the left and right subarrays.
5. Repeat until the complete array is sorted.

B. Randomized Quick Sort
1. Randomly select an element as the pivot.
2. Suppose the randomly selected pivot is 12.
3. Swap it with the last element.
4. Partition the array around the pivot.
5. Recursively sort both subarrays.
6. Repeat until the array is sorted.

 6. Time and Space Complexity
Deterministic Quick Sort
Case	      Time Complexity

Average Case	O(n log n)
Worst Case	O(n²)

Randomized Quick Sort
Case	       Time Complexity
Best Case	O(n log n)
Expected Case	O(n log n)
Worst Case	O(n²)

Space Complexity
Algorithm	              Average Space	Worst Space
Deterministic Quick Sort        O(log n)	O(n)
Randomized Quick Sort       	O(log n)        O(n)

Explanation:
- Best case: Pivot divides the array into nearly equal parts.
- Average case: Pivot divides the array reasonably well.
- Worst case: Pivot repeatedly becomes the smallest or largest element.
- Space: Memory is required for recursive function calls.
Important: Randomized Quick Sort reduces the probability of getting the worst case, but its theoretical worst-case time complexity is still O(n²).
