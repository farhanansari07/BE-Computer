import java.util.Scanner;

public class Knapsack01 {

    static int knapsack(int wt[], int profit[], int W, int n) {

        int dp[][] = new int[n + 1][W + 1];

        // Dynamic Programming
        for (int i = 0; i <= n; i++) {

            for (int w = 0; w <= W; w++) {

                if (i == 0 || w == 0) {
                    dp[i][w] = 0;
                }

                else if (wt[i - 1] <= w) {

                    dp[i][w] = Math.max(
                        profit[i - 1] + dp[i - 1][w - wt[i - 1]],
                        dp[i - 1][w]
                    );
                }

                else {
                    dp[i][w] = dp[i - 1][w];
                }
            }
        }

        return dp[n][W];
    }

    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        System.out.print("Enter number of items: ");
        int n = sc.nextInt();

        int wt[] = new int[n];
        int profit[] = new int[n];

        for (int i = 0; i < n; i++) {

            System.out.print("Enter weight of item " + (i + 1) + ": ");
            wt[i] = sc.nextInt();

            System.out.print("Enter profit of item " + (i + 1) + ": ");
            profit[i] = sc.nextInt();
        }

        System.out.print("Enter knapsack capacity: ");
        int W = sc.nextInt();

        int result = knapsack(wt, profit, W, n);

        System.out.println("Maximum Profit: " + result);

        sc.close();
    }
}

        for(int w=1;w<=W;w++){

                dp[i][w]=max(dp[i-1][w],profits[i-1]+dp[i-1][w-weights[i-1]]);
            }
            else{
                dp[i][w]=dp[i-1][w];
            }
        }

            maxProfit-=profits[i-1];
            w-=weights[i-1];
        }
    }


    return dp[n][W];
}

 1. Aim
To write a Java program to solve the 0/1 Knapsack Problem using Dynamic Programming and analyze its time and space complexity.

 2. Theory
The 0/1 Knapsack Problem is an optimization problem in which we are given a knapsack with a fixed capacity and a set of items, each having a weight and a profit.

The objective is to select items such that the total profit is maximum without exceeding the capacity of the knapsack.

It is called the 0/1 Knapsack Problem because:
- 1: Select the complete item.
- 0: Do not select the item.
We cannot divide an item into fractions.
Dynamic Programming
Dynamic Programming is a problem-solving technique that breaks a problem into smaller subproblems and stores their results to avoid repeated calculations.

In the 0/1 Knapsack Problem, we use a two-dimensional array dp[][] to store the maximum profit for different items and capacities.

Formula:
If the weight of the current item is less than or equal to the available capacity:
dp[i][w] = max(dp[i-1][w],profit[i-1]+dp[i-1][w-weight[i-1]])
Otherwise:
dp[i][w] = dp[i-1][w]

Where:
- i = Number of items considered.
- w = Current knapsack capacity.
- dp[i][w] = Maximum profit possible.
Base Conditions:
- If there are no items, profit = 0.
- If capacity is 0, profit = 0.

Real-Life Examples

1. Packing a Suitcase
You have limited luggage capacity and several items. You must choose complete items to maximize their total value.

2. Cargo Loading
A truck has limited weight capacity. The company selects complete packages to maximize their total value.

3. Project Selection
A company has a limited budget and must select complete projects to maximize expected profit.



 4. Algorithm
1. Start.
2. Read the number of items.
3. Read the weight and profit of each item.
4. Read the knapsack capacity.
5. Create a 2D DP array of size (n+1) × (capacity+1).
6. Initialize the first row and first column with 0.
7. Check each item:
   - If its weight is less than or equal to capacity, choose the maximum of including or excluding it.
   - Otherwise, exclude the item.
8. Store the maximum profit in the DP table.
9. Print the maximum profit.
10. Stop.

Step-by-Step Explanation
Given:
Item	Weight	Profit
1	10	60
2	20	100
3	30	120

Knapsack capacity = 50.

We have two choices for every item:
- Include the item.
- Exclude the item.
Step 1: Select Item 1 (weight 10, profit 60).

Step 2: Select Item 2 (weight 20, profit 100).

Total weight = 30 and total profit = 160.

Step 3: Consider Item 3 (weight 30, profit 120).

We cannot select all three because total weight would be 60, which exceeds capacity 50.

The best combination is Item 2 + Item 3.
Total\ Weight = 20+30=50
Maximum\ Profit = 100+120=220

Time and Space Complexity
Operation	Complexity
Creating DP table	O(n × W) space
Filling DP table	O(n × W) time
Overall Time Complexity	O(n × W)
Space Complexity	O(n × W)

Where:
- n = Number of items.
- W = Knapsack capacity.
Explanation:
- Time complexity is O(n × W) because we use two nested loops.
- Space complexity is O(n × W) because we store results in a 2D DP array.
Note: This is pseudo-polynomial time complexity because it depends on the numerical value of capacity W, not just the number of input bits.
